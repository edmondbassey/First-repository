# Edmond Bassey — selected work

A portfolio presenting Relay and Logbook through the engineering problems they address, with links to working demos, source code and implementation notes.

## Build

```sh
npm run build
python3 -m http.server 8765 --directory dist
```

No dependencies are required. The page uses semantic HTML, CSS and screenshots from the two fictional demo datasets. It has responsive layouts, keyboard focus states and reduced-motion support.

The project screenshots are actual browser captures of the working applications.
